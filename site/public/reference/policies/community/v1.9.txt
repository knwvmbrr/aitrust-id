Public conversation, respectful challenges and protected reports.

Public by choice
Public GitHub issues and discussions are the current community paths. Anyone can read; posting requires a GitHub account. The Townhall snapshot is dated and does not refresh automatically. Downloading a site draft is not posting. Public discussion is not training consent.

Read the live Townhall: https://github.com/knwvmbrr/aitrust-id/discussions
Code of conduct: /reference/conduct-policy.md

Challenge the finding
Use a small synthetic example, tag/method identifier, observed result and expected result. Attack the claim, not the person. Do not publish private AI answers, personal information, credentials, executable attacks or malware. Vulnerabilities and private conduct evidence need restricted reporting.

Report workflow: /#report
Private vulnerability reporting: https://github.com/knwvmbrr/aitrust-id/security/advisories/new

Moderation and appeals
Repository maintainers moderate the public spaces under the code of conduct. Seek review by a maintainer not involved in the original action where available. Public reasons and safe correction summaries support transparency without republishing removed personal information or unfixed exploits. A staffed appeal office and response-time SLA are not promised by this preview.

Private conduct contact: mailto:conduct@aitrustid.com

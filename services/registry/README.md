# Registry: deferred from 0.1

This image is a refusal launcher. Even explicitly enabling the `registry` Compose
profile exits with status 64 before a listener or database starts. It has no
published port, volume or network, and it does not install Streamlit or SQLite
application dependencies. Setting a future version environment value does not
enable it. Ordinary personal checking does not require this profile.

`prototype/` preserves the inactive historical dashboard proposal for inspection.
It has no implemented expiry, authorization, consent or production ingestion.
Hashes, origin hosts and capture times may identify or link information. Do not
use that prototype for real submissions. Modifying and running it is outside the
reviewed release; its presence is not an operational service promise.

The separate optional metadata research direction is still preserved under
N-011. Activation needs a reviewed service/data contract, explicit permissions,
retention and deletion, protected roles, recovery evidence and accepted release
configuration. This launcher is not a new registry implementation or a research
intake endpoint.

## Protect the user and bound the work

Linux-only initial profile. Before importing a model SDK, require actual nonroot/no-new-privs/capability-drop and a network namespace exposing only loopback/no external route. Absence of these facts is Unavailable, not a user-supplied allow flag. Qualification creates that namespace in an approved disposable hosted runner; no local Docker, model, framework install, GPU or new public endpoint. The public worker itself performs no network request and receives no cloud/HF/API credential, proxy or ambient HOME. Use a new private HOME/cache area; no user's existing HOME mutation.

Read an explicit regular no-follow input descriptor; check10MiB before allocation and full source identity before/after. Enforce4MP and existing supported PNG/JPEG container subset before decoder allocation, with fixed single-frame RGB8 decoding and bounded metadata/chunks/segments. Unsupported valid variants remain Unsupported/Unavailable, not corrupt, malicious or AI-generated. Do not honor remote/local URI metadata, EXIF rotation or color-profile instructions silently. Pin and report the selected byte/raster/crop identities in explicit JSON only.

Batch1, CPU threads1, inference mode, deterministic supported operations. Proposed wall 150s/CPU 120s/address-space8GiB/output16KiB/FD64 bounds, subject to actual hosted capacity measurement before runtime claims. Child initialization and ownership enter protected cleanup immediately after spawn; constructor/clock/selector faults must not leak it. Cancel/deadline kills and reaps only the owned unreaped group; known-reaped identifiers are never signalled. No background compiler, dataset walk, subprocess chosen by input, detached child or retry to another method. Exact supported process/SDK behavior must be observed, not assumed.

Hold model descriptors and use fixed `/proc/self/fd` paths to avoid reopening an input-selected model path. Stream large checkpoint digest checks instead of whole-file allocation; revalidate file identity/content after inference. A changed/truncated mapping can kill the isolated child and must become Unavailable. No universal hostile concurrent same-UID guarantee or forceful parent/host-crash recovery promise is made.

Default console output is a short reference logit plus limits; no filenames, raw metadata, image/embedding hash, entity or retained image. Explicit `--json` adds exact encoded-subject/model/preprocessing/source identities and a linkability warning; no raw image/embedding payload or auto-saved history. Raw score is NOT a probability, accepted origin tag, confidence, truth, authentication or local-edit detector. Center cropping can miss edits; unseen generator/camera/scene/compression families can produce harmful false accusations. Neither high nor low score determines AI/human authorship.

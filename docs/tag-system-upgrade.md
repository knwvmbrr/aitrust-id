# Tag system and deliberate sharing

Architecture: retain the compact code-only catalogue and existing accessible dialog
primitives. Describe the complete product in How tags work and About: distinct jobs,
multiple findings on one output, different evidence methods and independent gates.
PS is the first implementation; it is not a dependency or a substitute for other tags.
All 202 master scope records and pending taxonomy proposals are preserved unchanged.

Keep evaluation separate from disclosure. The default checker download uses an
explicit allowlist in `site/src/share-record.js`: PS state, public method hash,
preview status and a method reference. Never spread the evaluator record. Exclude
answer text, answer hashes, record IDs, lengths, spans, signal categories and future
unknown fields. The result itself can still be sensitive; this is minimization,
not an anonymity guarantee. Full evidence stays available through a distinct
checkbox-authorized detailed download. Editing/checking new input resets that choice.
Blind reviewer packets remain exact private research artifacts, not public summaries.
Report/contribution drafts contain user-written text and must be reviewed before posting.

Publisher wording was explicitly approved by the owner: Michael R. McGuire, an
individual, Michigan, United States. Display it on the catalogue, reference footer,
Legal panel and policy texts. This names the current operator; it does not create
an entity shield. Policies are reissued with verified corporate identity if operation
later transfers. No legal clearance or enforceability opinion is represented.

Policy 1.0 is preserved byte-for-byte at `/reference/policies/<slug>/v1.0.txt`.
Current version 1.1 adds identity and deliberate export controls. Each page offers
an actual text download with a filename, version and previous-version link.
The build rejects overwriting an existing version with changed text. Bump the
version for subsequent policy edits; retain the previous archive. Existing aliases
remain available. Browser checks click all nine downloads without JavaScript and
compare bytes with the governing source, rather than inferring usability from HTTP.

Risks: accidental disclosure through future fields, misleading multi-tag demos,
false legal identity, mutated policy history and mobile overflow. Mitigations:
allowlisted summaries; opt-in detailed export; explicitly illustrative examples;
owner-approved identity; immutable version paths; 320px/200% and accessibility tests.
No detector method, confidence floor, release threshold or data-collection grant changes.

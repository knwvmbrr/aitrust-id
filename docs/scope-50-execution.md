## First batch architecture, before implementation

The owner accepted a metadata-only optional research pilot and identified an
iPhone 14 Plus for real-device tests. Build a static, account-free owner guide
and optional feedback file builder alongside the existing checker. Use native
labelled controls, the existing typeface/theme and left-aligned reading layout.
Feedback uses a strict allowlist: PS, its method version, user-reported result,
failure category and structured usability feedback. Exclude examples, free text,
identity, subject hashes, timings and device fingerprints. Preview every exported
field. A download is a local file; nothing is submitted or enrolled. No new intake
endpoint, database connection or background reporting is introduced.

A pure validation module rejects unknown fields, versions and enum values.
UI edits invalidate the preview and prior permission. Tests exercise hostile
fields, invalid choices, stale previews, actual downloads, keyboard use, small
screens and both browser engines. No test labels become independent ground truth.

Publish a legal/operations source inventory and reviewed corrective clauses in
this repository. Separate current effective website policies from proposed
formation/contracts and restricted personal material. Inventory hashes establish
which originals were inspected, not legal correctness or adoption. Do not publish
credentials, personal dossiers, privileged advice or unreviewed contracts wholesale.
Record specific defects and unresolved professional/owner decisions.

## Risks and release limits

Metadata can still be identifying when combined; deliberately omit stable user
identifiers and event timestamps. User feedback is an observation, not a verified
accuracy label. Exports can be shared externally by their owner; the website
cannot revoke a downloaded copy. Future collection needs accepted retention,
access, withdrawal, backup/deletion and recovery rules before real submissions.
Offline open-source users may decline all sharing or modify the client. Hidden
telemetry would violate the product boundary and cannot make collection complete.

An owner's iPhone test demonstrates that device/workflow. Independent blinded
accuracy labels, Android/TalkBack, human desktop screen-reader review and outside
setup remain separate. No automatic source test can close them.

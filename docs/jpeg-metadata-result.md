Metadata is opaque and untrusted. This reader does not decode entropy/DCT/pixels,
prove image validity or determine color/orientation. Damaged entropy may pass
framing. Prefix-labelled Exif/XMP/ICC/JFIF and opaque APP/COM counts do not verify
those formats or any claimed editor/author. Missing metadata proves no origin.
Default prose omits file hashes, names and raw metadata; explicit JSON contains a
linkable encoded-file SHA256. The source file is not scrubbed or modified.

Only the documented single-scan 8-bit baseline 1/3-component selected profile is
supported. Other profiles and trailing data are refused. Resource limits and
fixed failure behaviour are described in [the guide](jpeg-metadata.md). Actual
current execution is synthetic macOS/CPython; current Linux, independent human,
phone/browser, accuracy and full FA/PA/F-155 acceptance are not established.

watermark verifier, production activation or tag release.

# Three C2PA dependency project-grant notices

This component delivers the actual release grants for btree-range-map0.7.2,
range-traits0.3.2 and static-regular-grammar2.0.2. Each checksummed release README
explicitly offers Apache-2.0 or MIT at the recipient's option. This delivery
chooses Apache-2.0 and carries the complete unchanged license, release grant and
publisher-declared authors. It adds no copyright year or ownership assertion.

The original crate/upstream LICENSE and NOTICE filename absence remains an
observation. These three text supplements are **AITrust-ID assembled carrying**,
not fabricated publisher files. Full C2PA native correspondence, other packages,
source-offer requirements, protected signing and actual SDK consumers remain
separate. This component grants no C2PA route, runtime, accuracy or project-wide
license clearance and closes no F-057/X-02 original requirement.

Use existing Python3.12+ on supported POSIX macOS/Linux. No dependency, SDK,
provider, credentials, native library or package execution is required. Create
an owner-private0700 parent outside every Git checkout, then choose a new path:

```sh
python3 -I -S -B scripts/c2pa-project-grants.py \
  --prepare /absolute/private-parent/C2PA-PROJECT-GRANTS.zip

python3 -I -S -B scripts/c2pa-project-grants.py \
  --inspect /absolute/private-parent/C2PA-PROJECT-GRANTS.zip
```

The artifact contains three `*-APACHE-2.0.txt` supplements and
`C2PA-PROJECT-GRANTS.json`. Its structured index binds the exact source grants,
selected license text and generated member bytes; a received index cannot
approve itself. A package assembler can call
`tools.c2pa_project_grants.expected()` for the exact four member byte strings.
The source manifest and input index are fixed independently of received bytes.

`--inspect` reconstructs trusted expected bytes, checks the complete received
artifact for equality **before ZIP interpretation**, then checks all four member
contents. It deliberately accepts only the deterministic stored ZIP encoding;
alternate compression/order/timestamps, omissions, modifications, coherent index
rebinding, trailing bytes and extra members refuse. A C2PA wheel or native library
is not this artifact and is not inspected or executed by this tool.

Preparation never overwrites an existing file or link and never deletes a file.
Successful files are0600 after fsync, full read-back, source/private-boundary
checks and close. An interrupted or failed write may leave private partial
output: the fixed `output_may_exist:true` warning means inspect before use and
choose a new destination after resolving the failure. It does not promise
rollback, atomic public publication or forensic deletion. The enclosing private
parent must stay0700; another principal or a compromised same-user process is
outside this filesystem integrity promise.

One operation is limited to16 captured reads,8,000,000 logical bytes (inside the
unchanged foundation64MB budget),80 actual joined descriptors including ancestry,
one original10-second finite nondecreasing clock, a128KiB artifact/expanded-byte
bound, exactly four generated members and32768 bytes per member. Stored ZIP
requires no decompression. Unknown sources or changed grant text refuse, rather
than silently switching to another license/project/version. See the
[recorded pre-code plan](c2pa-project-grants-plan.md).

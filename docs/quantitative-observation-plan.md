# Quantitative-detail observations — architecture before implementation

Implement the registered F-015 signal as a separate bounded English text observation. Detect supported literal numeric/date-shaped details and whether the same sentence contains a supported citation/URL marker. It does not establish specificity, truth, source validity, hallucination, malicious intent or authorship. HP/NF/FI remain unavailable; the public production allowlist is unchanged. This component does not require any model, account, hosted lookup or other tag.

Reuse Unicode-15 normalization, literal sentence units and safe fixed-error handling. Explicitly support ASCII digit tokens, standard separators and date-shaped tokens under finite input/count limits. Exclude marker-contained digits, URLs, obvious identifiers and clipped partial tokens. Do not convert strings to unbounded numbers or pretend that a syntactic date is a validated calendar date. Written-out numbers, unusual date formats, inferred contextual uncertainty, source resolution and citation support remain separate work.

Default output is a brief count record without text, hashes, URLs or spans. A new private detail report is opt-in, mode 0600 in an owner-held 0700 directory outside the checkout, with no overwrite or symlink following. Detail records bind the normalized subject, exact spans, marker spans and method identity. Warn that hashes/spans can reveal or link information. No free-text feedback, upload, persistence, new endpoint or browser permission is introduced.

Refuse empty/non-English-declared/invalid-Unicode/NUL/oversized inputs and wrong CLI parameters before evaluation. State unavailable on processing failure; no finding is never a safety clearance. Do not execute attachments or follow reference URLs. An optional failure cannot stop PS, corpus retrieval, receipts or other tags.

Verify real CLI behavior, Unicode normalization/span identity, citation-only numbers, decimals/grouping/date shape, code/identifiers, source markers, no implicit storage/network, malformed input, size/count bounds and private report permissions/overwrite/symlink failures. Execute Mac and an isolated non-root Linux route. Record source fingerprints and failures. These authored controls do not replace the independent semantic validation and eventual HP integration job; F-015 completion is assessed against its full named claim.

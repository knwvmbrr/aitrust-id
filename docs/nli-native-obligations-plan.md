## Deliverable and success contract

Cover all sixteen pinned native wheel occurrences across macOS arm64 and Linux
x86_64: PyYAML/LibYAML, hf-xet, ml_dtypes/Eigen, NumPy and its platform BLAS/Fortran
terms, ONNX vendored components, ONNX Runtime, protobuf/upb and tokenizers/Rust.
Build an offline machine-readable, source-bound graph whose packages expose
exact wheel/native identities, verbatim shipped and supplemental notice roles,
versioned source evidence, dependency relationships and specific retention/source
availability actions. Include actual reviewed license grants as evidence without
claiming legal clearance from a label or treating a missing filename as a ban.

Resolve actual missing notice/source inputs wherever exact publisher evidence
permits. An unresolved selected-build correspondence is stated precisely; it is
not a new reproducible-binary requirement. A source repository URL alone does not
fulfil an applicable covered-source or relinking obligation. Raw retained texts
are available to the real distribution graph, not hidden in an inventory count.

## Owned interfaces

New `tools/nli_native_obligations.py`, `scripts/verify-nli-native-obligations.py`,
focused tests, this plan/operator guide, immutable execution/review records and
`sbom/nli-native/{manifest.json,sources/*}`. No shared or old cohort edits.

Profile `nli-native-dependency-observations/v1`. Top-level `inputs` binds the old
cohort, both locks/provenances and selected source evidence; `sources` records
content-addressed path/SHA256/size; `packages` identifies name/version/platforms,
artifact SHA256, declared terms, notice paths, term actions, dependency IDs and
evidence paths. Exact coverage and gaps distinguish published source declarations
from actually observed binary members. Claims for permission, release, compiler
identity, binary reproduction and detector accuracy remain false.

`verify(root)` is offline and uses sequential descriptors, strict bounded JSON
and exact retained text checks. It independently reconstructs expected records;
mutable manifest flags cannot manufacture reviewed evidence or missing notices.
Optional explicit cache replay verifies exact wheel/archive hashes and retained
member bytes. A checkout-only check cannot claim fresh archive observation.
The sibling artifact graph consumes this interface lazily for NLI only.

## Acquisition and resource/security risks

Use existing pinned Mac/Linux wheel caches and retained publisher records first.
Additional public official source-only retrieval is bounded to16MiB per record,
128MiB for the lane, while keeping2GiB free. No model weights, package execution,
installation, credentials, license assent or global service changes. Keep source
archives/cache private; publish only useful exact notice/build/source metadata.
All source retrieval origins and observation hashes are recorded; they are not
publisher signatures or proofs of compiler equivalence.

Archives require preallocation limits, safe unique names, regular members only,
streaming expanded-byte limits including PAX metadata, and aggregate retained
text caps before reading/storing. ZIP readers reuse the unchanged reviewed NLI
header preflight before allocation. Refuse drift before/after replay and malformed
private CLI paths with fixed diagnostics. No raw private paths or commands enter
public reports. No optional cohort failure may disable another tag/tool.

# MT on-device phrase explorer — architecture

Deliver a reusable MT-modal component, not an MT tag assertion. The user explicitly
selects either existing urgency observations 1.1.0 or the authority quotation
candidate 1.0.0 and runs the preview. No analysis, runtime download or network
worker starts merely by mounting the component. English only; preserve the
8,000-character / 32,000-byte bounds and all original method meaning.

Package exact, unmodified Python method/support files and frozen Unicode15 data
in a deterministic, source-hashed bundle. Use a small separately versioned
Python adapter to return the original method record and safe result counts. The
adapter passes selected text as a function argument; input is never evaluated.
Include the project's LICENSE and NOTICE and the Unicode license verbatim. Keep
existing runtime third-party notices intact and link them from the preview.
Do not replace native source methods with an approximate JavaScript port.

A distinct lazy module Worker loads its own instance of the existing pinned
same-origin Pyodide runtime and verifies the bounded MT bundle and every embedded
member before writing an ephemeral in-memory filesystem. No PS worker/client,
method state or supervisor is imported. Every run owns a fresh worker. Success,
failure, six-second evaluation timeout, loading timeout, editing, changing the
method, clearing and component unmount terminate only this worker. A late result
cannot attach to changed input. Unsupported syntax returns Unavailable, never a
quiet finding count. No account, upload, storage, telemetry, file collection or
server endpoint is introduced. Shared static runtime delivery is infrastructure,
not shared analysis state; its availability is still a common prerequisite.

Use existing rounded brand tokens, normal native form controls, short copy,
explicit labels, adjacent errors and polite completion status. Results remain
in memory. The default view gives counts and a plain-language limit; optional
in-page details show method/source identity and numeric NFC codepoint locations,
not pasted text, an automatic download or sharing control. No confidence score,
combined vote, endorsement, manipulation or intent conclusion is shown.

Build an MT-only fixture outside published catalogue routes and verify it on an
owned random-port server with Chromium and WebKit. Check full result parity with
canonical Python authored controls, frozen normalization identities, malformed
quote/input refusal, tampered/oversized bundles, worker failure/timeouts, stale
input cancellation, no content persistence/requests/console, keyboard/reflow and
accessible form/result states. Preserve first failures. Physical iPhone and human
assistive-technology acceptance remain separate. PM owns shared mounting/build
integration after the working component is reviewed.

## User outcome and unchanged evidence boundary

Choose a local PNG or JPEG, then explicitly inspect it in the browser. See
bounded image-header facts and fixed metadata-section/category counts without
uploading the image, installing an SDK or exposing embedded values. Other valid
formats/variants remain Unsupported; damaged selected framing is distinguished
from unsupported profiles and runtime failure. An observed container is not a
pixel-validity, origin, signature, watermark, authorship or truth judgment.

Use the exact independently reviewed modules from source
8e1b1a23a1bef0659bf1ec567ceef647b5cd76a5:
`tools/png_metadata.py` (png-metadata-preflight/1.0.0) and
`tools/jpeg_metadata.py` (jpeg-metadata-observation/1.0.0). Preserve their method,
limits, grammar and license/NOTICE bytes in a distinct versioned source cohort.
Do not expand palette/interlaced/progressive/coding support or issue FA/PA. X-07
and the text-only gateway remain unchanged. This develops the image-evidence
capability under T-FA/T-PA/F-155, not their full accepted tag outcomes. Existing
C2PA inspection and canonical subject preparation remain separate.

## Explicit fixed projection, no arbitrary source execution

The existing modules include local filesystem and subprocess supervisors, which
are inappropriate inside a browser runtime. Derive a deny-by-default projection
of only the exact pure inspection declarations, not a JavaScript reimplementation.
The builder verifies the full original source digest and an explicit ordered
allowlist of every top-level AST node (kind, name, source-segment digest). The
selected pure imports/constants/ImageError/functions each have their own fixed
identity. An unknown/modified node, dependency or source fails before publication.
Excluded OS/file/process code is never executed by the browser. No input record
chooses a source, function, import, URL, interpreter or executable.

The versioned cohort retains the full originals. The source bundle includes only
the selected exact source segments plus a fixed wrapper; the manifest identifies
both original and projection digests. Native controls run the full unchanged
modules and separately the exact projection; browser controls compare complete
records against native output. Whole-record parity is fixed-example engineering
evidence, not independent semantic accuracy. A hash-verified canonical worker is
trusted; JavaScript's closed result/subject checks are not an independent replay
of every parser operation.

## Browser isolation, resource and identity controls

A separate lazy ImageMetadataExplorerSlot contains failures locally. Opening the
panel or selecting a file does not analyze it or start a worker. Explicit Inspect
starts one fresh dedicated worker. Existing PS/MT workers, other drafts and input
state are not shared. Root mounts the component later; this branch owns only new
files and a runnable standalone fixture.

Use an abortable FileReader and read a real Blob's intrinsic size before allocating file bytes: maximum 10 MiB,
no URL fetch and no reliance on the extension or MIME type. Use the encoded-byte
signature to select only PNG/JPEG. Hash and byte-count the captured bytes, transfer
the owned buffer, and validate a closed response bound to that exact subject,
parser/profile and pinned source projection. Reject unknown fields before render,
including raw metadata, filenames or paths. Captured encoded-byte identity does
not imply canonical decoded-pixel identity.

Retain the original 4-million-pixel/header, PNG 32-MiB expanded-image,
256-KiB stored/expanded metadata, 64-KiB text-field, 4096 chunk/marker and 8192-byte
output bounds. Startup/async capture is bounded to 45 seconds; evaluation is
bounded to 6 seconds; Cancel/edit/file change/Clear/unmount terminates the owned
worker and invalidates late replies. A timeout or worker/asset failure becomes
Unavailable, never zero findings. Source/manifest reads are capped, hashed and
fixed-path. Reuse the existing five exact Pyodide314.0.7 runtime assets and their
current notices; no dependency/model/network endpoint is introduced.

## Privacy and presentation

Only public method/runtime files may be requested. File bytes, names, raw metadata
and private results never enter a URL, request body, logs, account, storage,
research submission or telemetry. Default summaries omit the file hash and
embedded values. Exact JSON is deliberate private detail behind a linkability
warning; its hash/positions can identify copies. Native file input may display
the filename locally. Clear/unmount removes app references, not forensic erasure.
The source image remains unchanged and can still contain identifying metadata.

Show Unsupported separately from selected malformed-data and runtime failures.
PNG preflight checks only its documented framing/zlib scanline subset. JPEG
observations do not decode or validate entropy/pixels. Exif/XMP/ICC/JFIF labels,
APP11 and C2PA-shaped sections are untrusted/opaque presence observations; do not
present them as verified credentials or evidence of AI/human origin. No automatic
export. Existing brand tokens, native labels, short explanations, polite status,
44px controls and light/dark/320px enlarged-text checks apply.

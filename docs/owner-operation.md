# Owner operation and first physical-phone check

Start at https://aitrustid.com/reference/operate/ . The guide explains PS, two
synthetic practice cases, short result interpretation and an optional local
metadata feedback file. Nothing is submitted by that download.

The owner's first device is an iPhone 14 Plus. Record the actual iOS version,
Safari behavior, portrait/landscape, enlarged text, VoiceOver, prepared offline
check, result saving and removal. Do not prefill passing results. Return failures
with the step and method version; do not include a private AI conversation.

Practice establishes that the owner can operate this route. It is not independent
accuracy labeling. The two recruited reviewers must label a new frozen authorized
packet independently before seeing PS's answers. Android/TalkBack, desktop human
screen-reader and outside-user installation remain separate open requirements.

The first research pilot is metadata-only by owner acceptance: result, method
version, failure category and structured feedback. Example sharing requires a
separate later preview/redaction/permission flow. Retention and intake are still
unselected; this step cannot collect users centrally. No signup is required to
use the checker or make a local feedback file.

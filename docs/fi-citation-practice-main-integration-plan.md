# FI private citation practice: main integration

Plan recorded before implementation by Codex /root/web_camo, 2026-11-22.

## Outcome and architecture

Bring the independently reviewed fixed-example preparer from published commit
`a0e6c766d1d07af55d5541fefa51d7e8900c41fb` into ordinary main-source downloads.
Import its producer, focused tests and two guides byte-for-byte. The canonical
citation engine, CLI, corpus and frozen Unicode normalizer remain unchanged.
Add an explicit reference-guide copy to the existing site preparation allowlist,
and expose that guide and the main source download in FI's existing use section.
No new browser input, runtime worker, endpoint, dependency or taxonomy is added.

The two commands create a fixed invented packet in a selected private directory,
then use the existing canonical checker to distinguish one resolved association,
one unmapped supported marker and one unsupported marker form. These are citation
association observations, not source support, contradiction, truth or an FI tag.
FI stays planned and its full original acceptance remains open.

## Privacy, integrity and failure risks

- Private output is an explicit user choice: retain the reviewed0700 parent/new
  packet and0600 file rules, no overwrite, no-follow traversal, source stability
  checks, and explicit output-commit uncertainty. Abrupt termination may leave
  private files; do not promise crash-atomic cleanup or forensic erasure.
- Resolved means a declared association binds attached bytes, not correctness.
  Preserve the guide's caveats and short no-verdict usage wording.
- The optional preparer must not be imported by or become a prerequisite for the
  canonical checker, PS or any other tag. No input is uploaded or collected.
- Shared site edits are limited to the FI usage branch and one explicit guide
  copy. Root owns generated assets, inventories, changelog and publication.

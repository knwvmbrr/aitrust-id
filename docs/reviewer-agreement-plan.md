# Reviewer agreement — architecture before implementation

F-056 needs an actual agreement computation from separately collected MT ratings. Build the nominal-metric component independently of any detector, release or collection endpoint. It reads a bounded local JSON matrix with 2–32 reviewer aliases, 2–16 declared categorical values and up to 2,048 unique units. Only units with at least two supplied nonmissing ratings contribute to coincidence counts; unpaired values must not inflate the expected agreement. Use exact rational coincidence/disagreement arithmetic and the nominal formula from Krippendorff’s primary computational paper. A uniform single category or no paired ratings yields unavailable, never perfect agreement. Preserve negative coefficients and explicitly separate disagreement from accuracy.

The default report contains anonymous aggregate counts, the coefficient, its exact fraction, observed/expected disagreement and pairable-unit coverage. It emits no original examples, reviewer aliases, unit IDs, category names, input hashes or free text. No automatic submission or storage occurs. It cannot attest that distinct aliases represent independent people or that missingness is random. The existing MT alpha 0.55 remains an unaccepted candidate; comparisons cannot approve a release. Confidence intervals, MT annotation/adjudication protocol and real blinded human labels remain separate unfinished work.

Strict unique-key bounded JSON, exact allowed keys, typed and length-bounded aliases/ratings, no symlink input, fixed error messages and exclusive committed-run writes and atomic replaceable local output files protect users. No new dependencies, endpoint, service start, model, tag or calibration change is introduced. Test the author’s three worked nominal/binary/missingness examples, unpaired-value invariance, observer/item/category relabeling, variable-rater weighting, missing/constant/negative cases and privacy canaries. Execute the actual CLI on Mac and nonroot network-isolated Linux, refresh any affected source checks, and retain synthetic verification as synthetic rather than claiming real human acceptance.

Primary source: Klaus Krippendorff, Computing Krippendorff’s Alpha-Reliability, 2011, revised literature 2013: https://www.asc.upenn.edu/sites/default/files/2021-03/Computing%20Krippendorff%27s%20Alpha-Reliability.pdf . Implemented formulas and independently written synthetic vectors only; do not redistribute the paper.

Report destination failures are distinct from invalid rating data. Execute unsafe-output refusal and exclusive retained-report overwrite checks; an output failure prints no coefficient and does not modify the retained record.

# SEO audit and bounded fixes — 2026-11-16

Observed at 18:20 UTC. Owner: Codex SEO agent; integration owner: Codex PM.

## Architecture and risks

Keep the existing static reference routes, sitemap and canonical URLs. Generate each search/social description from the same plain-language purpose and availability that the corresponding page displays. This prevents an adopted but unavailable tag from appearing to be a working checker. Keep one shared metadata function for HTML and social summaries. No tracking, account gate, third-party script, keyword stuffing or invented validation claim is added.

The primary risk is a search snippet implying availability or accuracy that the page does not establish. The checks cover local-only privacy, unavailable adopted tags, self-operated organization software and unbuilt services separately. Native source and tag methods are outside this change.

## Confirmed findings and changes

1. **Availability mismatch in tag metadata.** Live MT's metadata described a development preview while its body said the checker was planned. The old helper used only `tag.proposed`; in source it also mislabeled available local enterprise software as a research proposal. The helper now uses the page's existing presentation purpose and availability. PS explicitly describes supported downloaded/encoded-code patterns; PII explicitly says it requires local setup; planned personal tags say no checker is available; working organization software says there is no hosted team service.

2. **Generic snippet copy concealed each tag's job.** All tag descriptions shared the same generic reading instruction. The new summaries explain each offering's actual purpose. Homepage metadata now leads with free, open-source AI-output checks and identifies PS's bounded preview. It does not promise broad truth verification, authorship detection or independent release accuracy.

3. **Overbroad default structured page type.** The default metadata emitted CollectionPage for individual operating guides and policies. Those now use WebPage; the catalogue roots retain CollectionPage. This is a semantic correction, not a rich-result or ranking promise.

4. **Seasonal browser chrome consistency.** The two static page templates now start with the Q4 light canvas theme color. The theme controller supplies the selected light/dark color once running. The separate web theme agent owns decorative rendering.

## Existing strengths retained

Tags have real static HTML routes; the reference index links every tag without JavaScript. These were not absent and were not rebuilt under a claim that SEO was missing.
